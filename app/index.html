CODESTRATA METHOD

        
CodeStrata 如何判断

      

      
    

    

      

        
会判断什么

        

          
项目用途
GitHub 简介与 Topics 所描述的仓库目标。

          
复用许可
许可证类型及二次开发时需要保留的约束。

          
维护结构
贡献者集中度、最近推送时间和停更风险。

          
项目体量
仓库大小与根目录结构所反映的接手成本。

          
活跃节奏
UTC 月度提交、活跃峰、断层与 Release。

        

      

      

        
不会判断什么

        
    
          
  • 不把 Stars 或单一指标当作代码质量总分。
    • 
          
  • 不执行项目测试，也不声称已经验证安全性或可运行性。
    • 
          
  • 不替代律师对许可证原文的法律判断。
    • 
          
  • 不读取、复制或分发仓库源码内容。
    • 
        

      

      

        
判断标签

        
宜 当前公开证据支持作为复用基线。

        
慎 先核对关键模块或维护状态，再决定复用。

        
险 存在许可证、维护集中或停更等明显风险，优先抽取结构。

      

      
数据来自公开 GitHub API；提交历史为有界采样，快照时间与数据来源会随结果一起展示。
